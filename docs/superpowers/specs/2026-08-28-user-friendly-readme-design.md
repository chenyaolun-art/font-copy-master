# Font Copy Master 普通用户 README 设计

## 目标

为第一次打开仓库的普通用户提供一个无需阅读代码即可理解、安装和使用 `font-effect-prompt-builder` 的中文入口。README 应在首屏回答三个问题：这是什么、能帮我做什么、怎样开始。

## 目标读者

- 想从美术字截图反推字体与视觉效果的设计师、运营和内容创作者
- 想为 GPT Image 2 生成可复用中文美术字提示词的普通用户
- 不假设读者熟悉 Git、Python、JSON 或 Codex Skill 的内部结构

## 信息结构

README 按以下顺序组织：

1. 项目名称与一句话价值说明
2. “它能做什么”：分析、换文案、归档三项核心能力
3. “三步使用”：上传参考图、提供目标文案、确认是否归档
4. 一段贴近真实对话的使用示例
5. Codex Skills 安装方法，提供复制目录与 Git 克隆两种方式
6. 输出内容说明：字体推测、字形改造、排版、效果层次、排除项和最终提示词
7. 存档说明：案例包含提示词、分类资料和参考图
8. 隐私提醒：只有明确确认后才本地归档；将案例提交到公开仓库会公开参考图
9. 能力边界与常见问题
10. 面向开发者的目录结构，放在页面末尾

## 文案与视觉语气

- 使用简体中文和短句，避免内部实现术语
- 先给可复制的使用话术，再解释技术细节
- 使用少量 Emoji 作为导航，不堆叠徽章或营销口号
- 不使用尚未获准公开的两张用户参考图
- 不声称可以百分之百识别具体字体；明确说明输出属于基于可见特征的推测

## GitHub 页面简介

仓库顶部简介使用：

> 从参考截图拆解美术字的字体、字形、排版与效果，生成 GPT Image 2 中文提示词，并可分类归档。

## 隐私边界

- 本次只向 GitHub 推送 README 与仓库简介
- 不推送当前本地存档中的用户截图、案例文件或索引更新
- README 明确提醒：公开提交存档会同时公开其中的参考图

## 验收标准

- 普通用户在首屏能理解项目用途
- 用户无需阅读 `SKILL.md` 就能找到安装和使用步骤
- 至少提供一个可直接复制的调用示例
- 清楚区分“生成提示词”与“直接生成图片”
- 明确说明字体识别的不确定性与案例图片的隐私风险
- 所有仓库内相对链接有效
- GitHub 顶部简介与 README 定位一致
