# 本地字体案例预览页设计

## 目标

为 `font-effect-prompt-builder` 提供一个无需服务器、双击即可打开的本地案例画廊，解决字体案例难以回看、比较和复制提示词的问题。

## 使用方式

生成后的页面保存为案例库内的 `preview.html`。用户可以直接以 `file://` 打开，无需安装依赖或启动后台服务。每次成功归档新案例后重新运行生成器，页面即可收录最新内容。

## 架构

新增独立生成脚本 `font-effect-prompt-builder/scripts/build_preview.py`。脚本读取指定案例库中的 `index.jsonl`、各案例的 `case.md` 与参考图，将结构化资料和图片转换为内嵌 JSON 与 data URL，输出一个自包含 HTML 文件。

静态页面不在浏览器端读取本地文件，因此不会遇到 `file://` 跨域限制。页面不使用外部字体、框架、CDN、网络请求或后台服务。

## 页面结构

1. 顶部区域显示页面标题、案例数量、搜索框和排序选项。
2. 筛选区提供语种、风格与效果标签筛选，并支持一键清除。
3. 主区域使用响应式卡片网格展示参考图、来源文案、目标文案和主要标签。
4. 点击卡片打开详情面板，显示大图、字体分类、可见特征、完整提示词与案例编号。
5. 详情面板提供“复制原始提示词”和“复制终版提示词”按钮，并显示复制成功或失败状态。
6. 无匹配结果、图片缺失或案例字段不完整时显示明确的空状态或降级内容。

## 视觉设计

采用深海军蓝背景与冰白、淡青紫强调色，呼应现有字体案例但不与参考图争夺注意力。卡片以图片为主，文字信息保持紧凑；交互仅使用轻微淡入、悬停抬升和焦点高亮。桌面端使用多列网格，窄屏自动切换为单列。

## 数据流

1. 生成器验证案例库目录与索引。
2. 按索引顺序读取案例记录和对应 `case.md`。
3. 解析来源文案、目标文案、字体分析、原始提示词和终版提示词。
4. 读取参考图并以内嵌 data URL 写入页面。
5. 将案例数据序列化进 HTML，浏览器端仅负责搜索、筛选、排序、详情显示与复制。

## 归档集成

`SKILL.md` 的归档步骤在案例写入成功后运行生成器，以安装版 Skill 的 `library` 为数据源，更新同目录的 `preview.html`。预览生成失败不得回滚已成功归档的案例，但必须明确报告失败原因。

## 错误处理

- 索引不存在、JSONL 无效或输出目录不可写时，生成器返回非零状态并给出可理解的错误。
- 单个案例缺少说明文件或参考图时，跳过该案例并报告警告，其余案例继续生成。
- 提示词或分析字段缺失时，以空状态显示，不伪造内容。
- 剪贴板 API 不可用时，复制按钮降级为选中文本并提示手动复制。

## 验证

- 使用临时案例库测试生成器对正常索引、缺失图片、无效 JSONL 和空案例库的处理。
- 确认输出 HTML 不包含外部网络依赖，可通过 `file://` 打开。
- 确认已安装案例库中的全部索引记录都出现在页面数据中。
- 在桌面与窄屏尺寸检查卡片、筛选、详情面板和复制按钮。
- 检查键盘焦点、按钮标签、颜色对比与减少动画偏好。

## 范围边界

首版仅做本地浏览、筛选和复制，不提供在线生成图片、编辑案例、删除案例、云同步或用户账号功能。
