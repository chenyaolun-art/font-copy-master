# 分類法

依可見證據選最少且準確的標籤。`style_tags` 和 `effect_tags` 可多選；任何欄位使用 `other` 時，`classification_notes` 必填並說明原因。

| 欄位 | 允許值 |
| --- | --- |
| `language` | `arabic-language`, `cyrillic-language`, `japanese`, `korean`, `latin-language`, `mixed`, `other`, `simplified-chinese`, `traditional-chinese` |
| `script` | `arabic`, `cyrillic`, `han`, `hangul`, `hiragana-katakana`, `latin`, `mixed`, `other` |
| `style_tags` | `cute`, `editorial`, `elegant`, `energetic`, `fantasy`, `futuristic`, `handwritten`, `horror`, `industrial`, `luxury`, `other`, `playful`, `retro`, `street`, `traditional` |
| `effect_tags` | `bevel`, `brush`, `chrome`, `distressed`, `embroidery`, `extrusion-3d`, `flame`, `flat`, `glass`, `glossy`, `glow`, `gold`, `gradient`, `ice`, `ink`, `inline`, `liquid`, `metallic`, `neon`, `other`, `outline`, `paper`, `plastic`, `shadow` |
