# 視覺分析

以可見幾何為最高證據，其次是字體類別，最後才列最多 1–3 個命名字體候選。不可由截圖單獨把命名字體判為高信心：高＝多個清晰字形特徵與類別一致，仍註明限制；中＝類別明確但候選有競爭；低＝文字、解析度或遮擋不足。若筆畫、連字、端點或比例反覆違反字型規律，判為客製字形／手工 lettering，而非硬套字體名稱。

依下列標題輸出：

## 文字與語種

抄錄可辨來源文字；不確定即提問。判定語種與文字系統，並說明混用或辨識限制。

## 字體推測

先給類別，再列 1–3 個候選、信心與可見證據。檢查字形骨架、寬度、字重、端點、內白、筆畫對比、傾斜；中文另看部件比例與收筆，拉丁字另看 x-height、襯線與字母形狀。

## 字形改造

列出可觀察的拉寬／壓縮、圓角、連筆、替代字形、誇張端點、局部扭曲與手工修飾；未見則明說無。

## 排版

記錄字距、字偶距、行距、換行、基線、對齊、重疊、傾角與整體構圖。只調整這些以容納新文案，不改變文字本身。

## 效果層次

由內而外描述：填色／紋理、內線、描邊、倒角、擠出、陰影、光暈、反光；補充光源方向、材質與明暗。截圖中的人物、物件或場景不會自動成為字效。

## 應排除元素

建立保留／排除清單：保留字體與附著效果；排除不屬於字體的背景、人物、場景物件、道具、圖示、邊框、標誌、水印、額外文字與裝飾。
