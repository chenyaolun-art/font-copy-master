# GPT Image 2 提示詞規格

依據 OpenAI 官方 [GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)：用清楚、具體的構圖與文字限制；將要渲染的文字逐字放在引號內且只出現一次。這是強約束，不能保證零文字誤差。把不可改變的規則與可調的版面分開；修訂時一次只改一項。

若介面支援，設定 `background="transparent"` 並輸出 PNG 或 WebP alpha，並排除所有實色背板。僅在無法透明時，才允許一個純色高對比回退背景。明確排除場景、棋盤格、非預期陰影、額外文字與水印；但原設計附著陰影應保留。

## 平滑與降噪（每段提示詞必填）

每段原始與終版提示詞都要加入以下品質方向：筆畫表面細緻平滑、色塊均勻、輪廓清晰、邊緣乾淨並具有高品質抗鋸齒。參考圖明確存在的飛白、乾刷、紙張或金粉紋理，只在對應位置少量、局部、受控地保留，不得擴散成全局噪點。明確排除粗糙砂礫、隨機顆粒、髒污斑點、鋸齒、彩色邊緣、毛躁光暈、過度銳化、色帶與壓縮雜訊。

「平滑」約束的是渲染與材質品質，不是把毛筆字改成圓體，也不是抹除參考圖必需的尖銳收鋒、局部飛白或手工輪廓。

## 可直接複製的模板

```text
製作一張孤立的美術字資產，唯一目標是渲染精確文字「{目標文案}」。文字必須逐字完全一致，僅出現一次，不得增刪、改寫或加入任何其他文字。字形採 {可觀察字體類別與骨架特徵}，並保留 {可觀察字形改造}；不要只依賴字體名稱。版面為 {對齊、換行、字距、基線與比例}，可因字數微調間距，但不得改變引號內文案。由內而外：{填色／紋理}、{內線}、{描邊}、{倒角或擠出}、{附著陰影／光暈／反光}；光源與材質為 {描述}。品質控制：筆畫表面細緻平滑、色塊均勻、輪廓清晰、邊緣乾淨且具高品質抗鋸齒；可見紋理僅在對應位置少量、局部、受控地保留。排除全局粗糙顆粒、砂礫噪點、髒污斑點、鋸齒、彩色邊緣、毛躁光暈、過度銳化與壓縮雜訊；不要因此改變字形骨架、尖銳收鋒或必要飛白。只保留文字和附著效果；可設定時使用完全透明背景、background="transparent" 與 PNG/WebP alpha，並排除所有實色背板；僅在無法透明時，允許一個純色高對比回退背景。排除額外文字、符號、圖示、人物、道具、場景、邊框、標誌、水印、棋盤格、無關裝飾及非預期陰影。
```

## 範例：夏日氣泡

```text
製作一張孤立的美術字資產，唯一目標是渲染精確文字「夏日氣泡」。文字逐字完全一致，僅出現一次。圓潤、寬體的手寫中文骨架，轉角飽滿，筆畫末端如充氣軟管；置中單行、字距緊密。由內而外：湖水藍到薄荷綠漸層填色、白色細內線、深青綠描邊、柔和高光與右下方附著陰影，透明果凍塑膠質感。品質控制：筆畫表面細緻平滑、色塊均勻、輪廓清晰、邊緣乾淨且具高品質抗鋸齒；排除全局粗糙顆粒、隨機噪點、髒污斑點、鋸齒、彩色邊緣、毛躁光暈、過度銳化與壓縮雜訊。只保留文字與附著效果；可設定時使用完全透明背景、background="transparent" 與 PNG/WebP alpha，並排除所有實色背板；僅在無法透明時，允許一個純色高對比回退背景。排除額外文字、符號、人物、道具、場景、邊框、標誌、水印、棋盤格、無關裝飾及非預期陰影。
```
