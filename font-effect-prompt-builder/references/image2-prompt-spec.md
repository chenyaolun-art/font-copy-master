# GPT Image 2 提示詞規格

依據 OpenAI 官方 [GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)：用清楚、具體的構圖與文字限制；將要渲染的文字逐字放在引號內且只出現一次。這是強約束，不能保證零文字誤差。把不可改變的規則與可調的版面分開；修訂時一次只改一項。

若介面支援，設定 `background="transparent"` 並輸出 PNG 或 WebP alpha。否則使用純色高對比回退背景。明確排除場景、實色背板、棋盤格、非預期陰影、額外文字與水印；但原設計附著陰影應保留。

## 可直接複製的模板

```text
製作一張孤立的美術字資產，唯一目標是渲染精確文字「{目標文案}」。文字必須逐字完全一致，僅出現一次，不得增刪、改寫或加入任何其他文字。字形採 {可觀察字體類別與骨架特徵}，並保留 {可觀察字形改造}；不要只依賴字體名稱。版面為 {對齊、換行、字距、基線與比例}，可因字數微調間距，但不得改變引號內文案。由內而外：{填色／紋理}、{內線}、{描邊}、{倒角或擠出}、{附著陰影／光暈／反光}；光源與材質為 {描述}。只保留文字和附著效果，完全透明背景；可設定時使用 background="transparent" 與 PNG/WebP alpha，否則純色高對比背景。排除額外文字、符號、圖示、人物、道具、場景、邊框、標誌、水印、棋盤格、無關裝飾及非預期陰影。
```

## 範例：夏日氣泡

```text
製作一張孤立的美術字資產，唯一目標是渲染精確文字「夏日氣泡」。文字逐字完全一致，僅出現一次。圓潤、寬體的手寫中文骨架，轉角飽滿，筆畫末端如充氣軟管；置中單行、字距緊密。由內而外：湖水藍到薄荷綠漸層填色、白色細內線、深青綠描邊、柔和高光與右下方附著陰影，透明果凍塑膠質感。只保留文字與附著效果，完全透明背景；可設定時使用 background="transparent" 與 PNG/WebP alpha，否則純色高對比背景。排除額外文字、符號、人物、道具、場景、邊框、標誌、水印、棋盤格、無關裝飾及非預期陰影。
```
